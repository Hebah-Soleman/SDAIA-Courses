# Prerequisites

Before attending **Day 1**, we assume you already have:

- **Working Python knowledge**, including:
  - Functions
  - Classes
  - Virtual environments (`uv` or `venv`)
- **Comfort with web technologies**, including:
  - HTTP
  - REST APIs
  - JSON payloads
- **Basic awareness of Large Language Models (LLMs)** at a user level.
  - Advanced topics such as **Context Engineering**, **Retrieval-Augmented Generation (RAG)**, and LLM architectures will be covered during the course.
- **Git and command-line basics**
